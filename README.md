Personal Spending Tracker


Questions
The following questions will be investigated using the collected spending data:

1. Which spending category has the highest total expenditure?
    * Compare the total amount spent across categories such as Groceries, Transport, Takeaway and Petrol.
2. Which payment method is used most frequently?
    * Analyse the number of transactions made using AIB and Revolut to identify which account is used more often.
3. At what time of day do I spend the most money?
    * Analyse transaction times to identify whether most spending occurs in the morning, afternoon or evening.


Description Of the Project

This project is about collecting and recording my personal spending data from AIB & Revolut. The dataset is manually collected and stored in a CSV file (data.csv). Each row represents an individual transaction. My aim is to track daily transactions, identify spending habits and analyse where my money is being spent.

The Dataset

The dataset contains the following columns:

* Transaction date and time.
* Shop or merchant name.
* Spending category.
* Transaction amount.
* Payment method.
* Transaction type.


Data Collection Method

Data is collected manually by reviewing personal banking transactions and recording the relevant information in the CSV file.
To maintain consistency throughout the dataset, the following rules are used:

1. Dates are recorded in DD/MM/YYYY format.
2. Times are recorded using the 24-hour clock (HH:MM).
3. All transaction amounts are recorded in Euro 
4. Shop names are recorded using their transaction descriptions.
5. Categories are assigned based on the type of purchase.
6. Payment methods identify the bank or account used.
7. Transaction types identify how the payment was completed.
8. Each transaction is recorded as a separate row.
